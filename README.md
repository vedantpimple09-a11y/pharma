# CHEMORA V5 — Premium Aesthetic Pharma Website

Bright, editorial, image-led corporate portal for APIs, intermediates, specialty chemicals and custom manufacturing.

## V5 upgrades
- Product Finder with name/CAS/formula/purity/category filters
- Certificate library filters
- 3-step RFQ wizard with review state
- Smooth reveal and hover animations with reduced-motion support
- Premium glass navigation and card interactions
- Fully responsive/mobile-first layout
- Local image library: every major visual can be manually replaced

## Run
Open `index.html` in a browser, or use VS Code Live Server for the smoothest local preview.

## Replace photos
Go to `assets/images/` and `assets/images/components/`. Keep filenames unchanged when swapping images.

## Production checklist
Replace demo copy/statistics, add verified client certificates, connect RFQ/contact forms to a secure backend/CRM, add privacy/terms/cookie/legal pages, and use only licensed/client-owned photography.
